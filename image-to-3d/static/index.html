Bambu Labs X1 Carbon Print Settings

Lithophane

Filament: White PLA / Translucent PETG
Layer height: 0.1 mm
Infill: 100%
Print orientation: stand vertically on edge for best detail.
Hold up to a window or LED panel to see the image.

Relief / Emboss

Filament: Any PLA / PETG
Layer height: 0.1–0.2 mm
Infill: 15–20%
Supports: Off
Works great for logos, portraits, and artwork.

Bambu Studio Setup

Open Bambu Studio → File → Import STL.
Select X1 Carbon profile.
Use 0.4 mm nozzle for detail.
Enable AMS for multi-color reliefs.

Best Photo Tips

High-contrast images work best.
Portraits: use a plain background.
For lithophanes, B&W photos give the sharpest results.
Larger prints (120–150 mm) show more detail.
